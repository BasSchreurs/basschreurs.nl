Project 2 - Bassinga | 🌐 Website | 📦 Github

Bassinga is een passieproject om behendiger te worden in het creëren van webapplicaties. Ik speel zelf basgitaar en wilde een tool om al mijn oefeningen op één plek te hebben.
De kern van Bassinga is een rollende tabnotatie-speler die ik zelf heb bedacht en ontwikkeld. Via een menu kies je een nummer, waarna de tabnotatie automatisch van rechts naar links scrolt als een teleprompter op eigen tempo.
De snelheid is instelbaar en de speler kan worden gepauzeerd. Daarnaast beschikt Bassinga over een tuner waarmee je de basgitaar kunt stemmen en kunt zien welke noot je speelt.

Dit was een goede test voor mij, aangezien ik op een klassiek probleem liep. In eerste instantie werkte de tuner helaas alleen lokaal. Dit kwam doordat de tuner toegang nodig had tot de microfoon van de gebruiker, iets wat niet server-side kan worden afgehandeld. Ik heb dit opgelost door de tuner client-side in de browser te laten werken, waardoor de microfoon rechtstreeks vanaf het apparaat van de gebruiker kan worden benaderd.
