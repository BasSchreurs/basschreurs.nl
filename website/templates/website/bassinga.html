Project 4 - Bassinga | 🌐 Website | 📦 Github

De kern van Bassinga is een zelfgebouwde tabnotatie-speler waarmee ik nummers in mijn eigen tempo kan oefenen. De tabnotatie scrollt automatisch van rechts naar links, vergelijkbaar met een teleprompter. De snelheid is instelbaar en de speler kan worden gepauzeerd. Daarnaast beschikt Bassinga over een tuner waarmee je de basgitaar kunt stemmen en kunt zien welke muzieknoot je speelt.

Wat heb ik geleerd

Dit was een goede test voor mij, aangezien ik op een klassiek probleem liep. In eerste instantie werkte de tuner helaas alleen lokaal. Dit kwam doordat de tuner toegang nodig had tot de microfoon van de gebruiker, iets wat niet op de server kan worden afgehandeld. Ik heb dit opgelost door de tuner client-side in de browser te laten werken. Hierdoor kan de microfoon rechtstreeks vanaf het apparaat van de gebruiker worden benaderd.

Gebouwd met:
  • Python & Django
  • JavaScript
  • HTML & CSS
  • SQLite
  • Nginx, Gunicorn & Docker
Functionaliteit:
  • Rollende tabnotatie-speler met instelbare snelheid en pauzeerfunctie.
  • Nummers aanmaken en opslaan via het Django admin panel.
  • Ingebouwde tuner om de basgitaar te stemmen en noten te herkennen.
