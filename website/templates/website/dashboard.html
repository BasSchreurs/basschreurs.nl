Dit dashboard ontwikkelde ik als persoonlijke startpagina: een centrale plek waar ik alles wat ik dagelijks gebruik bij de hand heb.
Het is gebouwd met Django als backend en JavaScript voor de frontend. Tijdens dit project heb ik ervaring opgedaan met het integreren van externe API's en RSS-feeds, waaronder OpenWeatherMap voor het weer en de NOS voor het laatste nieuws.

Gebouwd met:
  • Python & Django
  • JavaScript
  • HTML & CSS
  • API's
  • RSS Feeds
  • Nginx, Gunicorn & Docker
