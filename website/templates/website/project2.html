Project 2 - Bassinga | Website | Github

Bassinga is een passieproject om behendiger te worden met het creëren van webapplicaties. Ik speel zelf basgitaar en wilde een tool om al mijn oefeningen op één plek te hebben. Een plek die theorie en praktijk samenbrengt.
De kern van Bassinga is een rollende tabnotatie-speler die ik zelf heb bedacht en ontwikkeld. Via een menu kies je een nummer, waarna de tabnotatie automatisch van rechts naar links scrolt als een teleprompter op eigen tempo.
De snelheid is instelbaar en de speler kan worden gepauzeerd. Daarnaast beschikt Bassinga over een tuner waarmee je de basgitaar kunt stemmen en kunt zien welke noot je speelt. De tuner werkt helaas alleen local, omdat de app op een server wordt gehost zonder geluidskaart.

Gebouwd met:
  • Python & Django
  • JavaScript
    • Screenshots:

  • HTML & CSS
  • SQLite
  • Nginx, Gunicorn & docker(VPS)
Functionaliteit:
  • Rollende tabnotatie-speler met instelbare snelheid en pauzeerfunctie.
  • Nummers aanmaken en opslaan via het Django admin panel.
  • Ingebouwde tuner om de basgitaar te stemmen en noten te herkennen.
