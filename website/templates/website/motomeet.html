Project 3 - MotoMeet | 🌐 Website | 📦 Github

Het is mooi weer, je kijkt naar je motor en wil er op uit, maar waar ga je naartoe, en met wie? Voor veel motorrijders begint die zoektocht in een wirwar van Facebook-groepen, verouderde forums en appgroepen. MotoMeet lost dat op: een platform waar meet-ups overzichtelijk per datum georganiseerd staan, zodat je je kunt aansluiten bij een rit, andere rijders leert kennen en een community opbouwt.

Gebouwd met:
  • Python & Django
  • HTML & CSS
  • SQLite
  • Nginx, Gunicorn & docker(VPS)
Functionaliteit:
  • Profiel registreren (ook met Google)
  • Meetups aanmaken, bewerken en verwijderen (alleen voor geregistreerde gebruikers)
  • Publieke & privé meet-ups
  • Aanmelden & afmelden voor meetups
  • Comments plaatsen
  • Vrienden zoeken & toevoegen
  • Nieuwsartikelen schrijven via admin met Summernote
Wat heb ik geleerd:
  • Dit project leerde mij dat een idee nog maar het begin is. Het echte werk zit in de logica erachter — hoe structureer je een database, hoe zorg je dat gebruikers alleen zien wat ze mogen zien, en hoe vertaal je dat naar een interface die logisch aanvoelt? Van databaseschema tot deployment op een eigen VPS heb ik de volledige cyclus doorlopen.
