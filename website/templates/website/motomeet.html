Project 3 - MotoMeet | 🌐 Website | 📦 Github

MotoMeet is een social media platform voor motorrijders, ontwikkeld als grootschalig full stack project. Ik heb de applicatie zelfstandig van begin tot eind ontworpen en gebouwd, waardoor ik veel beter ben gaan begrijpen hoe je een applicatie structureert.
Gebruikers kunnen met elkaar communiceren, ritten en meet-ups organiseren en zich bij anderen aansluiten.

Gebouwd met:
  • Python & Django
  • HTML & CSS
  • SQLite
  • Nginx, Gunicorn & Docker
Functionaliteit:
  • Profiel registreren (ook met Google)
  • Meetups aanmaken, bewerken en verwijderen (alleen voor geregistreerde gebruikers)
  • Publieke & privé meet-ups
  • Aanmelden & afmelden voor meetups
  • Comments plaatsen
  • Vrienden zoeken & toevoegen
  • Nieuwsartikelen schrijven via admin met Summernote
Wat heb ik geleerd

Dit project heb ik zelfstandig ontwikkeld, zonder een vast tutorialtraject te volgen. Daardoor heb ik veel geleerd over het oplossen van technische problemen en het maken van keuzes rondom databases, applicatielogica en gebruikersrechten. Van het eerste databaseschema tot deployment op een eigen server heb ik de volledige ontwikkelcyclus doorlopen.
