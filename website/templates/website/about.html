About

Ik ben een back-end developer met een sterke interesse in het bouwen van schaalbare en doordachte webapplicaties. Mijn kennis heb ik volledig via zelfstudie opgebouwd, waarbij ik mij heb gefocust op Python en webontwikkeling.

Mijn interesse in back-end development komt voort uit nieuwsgierigheid naar hoe systemen achter de schermen werken. Ik wil begrijpen hoe alles samenkomt: van database tot API en van logica tot een werkende applicatie. Het bouwen van iets vanaf nul en dit stap voor stap zien groeien tot een functioneel geheel geeft mij veel voldoening.

Tot nu toe heb ik dit leerproces grotendeels zelfstandig doorlopen. Daarbij heb ik niet alleen technische vaardigheden ontwikkeld, maar ook geleerd om gestructureerd te werken, door te zetten en zelfstandig problemen op te lossen.
