Het Personal Dashboard is mijn persoonlijke startpagina gebouwd met Django. Het weer, nieuws, zoekopdrachten en notities. Alles wat ik nodig heb direct op één plek. Meer info →

Project 4 - Bassinga | 🚧 Work in progress

Bassinga is een persoonlijk project waarbij ik een webapplicatie heb gebouwd voor mijn hobby. Ik speel basgitaar en wilde een tool voor mijn oefeningen. De kern is een zelfgebouwde tabnotatie-speler die nummers als een teleprompter afspeelt. Dit aangevuld met een tuner die de noten toont die je speelt. Daarnaast ben ik bezig met het bouwen van een tool die youtube links omzet naar tabnotatie. Hiervoor gebruik ik een AI model, die audio omzet naar muzieknoten. Meer info →
