Server Setup & Workflow

Hier is een overzicht van mijn server setup en workflow. Ik host meerdere Django-projecten op één VPS, elk draaiend in zijn eigen Docker-container, met nginx als reverse proxy die het verkeer naar de juiste container verwijst. Ik maak verbinding met mijn server via de terminal met SSH.

Docker containers

Elk project draait in zijn eigen Docker-container. Hieronder zie je de output van docker ps, met alle containers die op dit moment actief zijn.


Deploy workflow

Ik werk local en push wijzigingen via Git. Vervolgens log ik in op mijn server voorgit pullvan de nieuwe versie, en herbouw ik de betreffende container(s) met docker compose up --build -d.



Nginx, SSL-certificaten en port forwarding

Eén nginx-container fungeert als reverse proxy voor drie verschillende domeinen. Op basis van de Host-header die de browser meestuurt, weet nginx welk domein de bezoeker wil bereiken en stuurt het verkeer naar de juiste Docker-container. Elk domein heeft een eigen SSL-certificaat via Let's Encrypt, zodat al het verkeer versleuteld verloopt (HTTPS).

Binnen elk domein gebruik ik location-blocks om verkeer op basis van het pad naar verschillende containers te sturen. Zo draaien er op basschreurs.nl bijvoorbeeld meerdere sub-projecten (zoals /littlelemon/ en /home/) die elk naar hun eigen container worden doorgestuurd, terwijl al het overige verkeer naar mijn hoofdportfolio gaat. 

server {
    listen 80;
    server_name basschreurs.nl www.basschreurs.nl;
    return 301 https://$host$request_uri;
}

server {
    listen 443 ssl;
    server_name basschreurs.nl www.basschreurs.nl;

    ssl_certificate /etc/letsencrypt/live/basschreurs.nl/fullchain.pem;
    ssl_certificate_key /etc/letsencrypt/live/basschreurs.nl/privkey.pem;

    location /static/ {
        alias /app/staticfiles/;
    }

    location /littlelemon/static/ {
        alias /app/littlelemon_staticfiles/;
    }

    location /littlelemon/ {
        proxy_pass http://littlelemon-web-1:8001/;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
    }

    location /home/static/ {
        alias /app/dashboard_staticfiles/;
    }

    location /home/ {
        proxy_pass http://dashboard-web-1:8004/;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
    }

    location / {
        proxy_pass http://web:8000;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
    }
}
